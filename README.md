# Quiz de Segurança Digital

Quiz interativo com 20 questões (5 partes de 4 questões), nível básico a intermediário, sobre segurança digital.

Ao final, mostra:
- pontuação total;
- gráfico de pizza geral (acertos x erros, com porcentagens);
- gráfico de pizza de cada parte;
- detalhamento das questões erradas, com a resposta correta e a explicação.

## Como usar

Não precisa instalar nada. Basta abrir o arquivo `index.html` no navegador.

## Publicar no GitHub Pages

1. Envie `index.html` e este `README.md` para um repositório.
2. No repositório, vá em **Settings > Pages**.
3. Em **Branch**, escolha `main` e a pasta `/ (root)`, e clique em **Save**.
4. Após alguns minutos, o site estará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Tecnologias

HTML, CSS e JavaScript puro, sem dependências. Os gráficos são SVG gerados no próprio código.
